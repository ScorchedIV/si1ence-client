### Combat Settings

- **Render Distance**: Adjusted per preset for visual clarity
- **Particle Reduction**: Lower particles = cleaner view during fights
- **Shadow Reduction**: Toggle for extra FPS boost
- **Crosshair**: Toggle custom combat crosshair
- **FPS Meter**: Monitor frame rate in real-time
